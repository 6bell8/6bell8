### 안녕하세요, 프론트엔드와 API 연동 실무를 중심으로 일하고 있는 개발자입니다.

<sub>
React 기반 관리자 페이지 개발과 RESTful API 연동, 인터페이스 정의 업무를 수행해왔습니다.  
현재는 AICC 프로젝트에서 보이스봇/챗봇 서비스 구축 및 운영 지원 업무를 담당하고 있습니다.  
고객사 요구사항을 반영한 기능 구현과 동적노드 로직 설계를 함께 진행하고 있습니다.  
화면 구현에 그치지 않고, 서비스 운영 흐름과 안정성까지 고려하는 개발을 지향합니다.  
개발과 운영 사이를 이해하며 실무에 바로 기여할 수 있는 개발자로 성장하고 있습니다.
</sub>
