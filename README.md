<h2> API와 서버·DB 흐름을 이해하는 AI 웹솔루션 개발자 박진성입니다.</h2>

<sub>
React 기반 웹 화면 개발, API 인터페이스 설계, 동적노드 개발을 중심으로 실무를 경험해왔습니다.<br/>
현재는 AICC(인공지능 컨택센터) 프로젝트에서 보이스봇/챗봇 서비스 구축 및 운영 업무를 수행하며,<br/>
고객사 요구사항을 반영한 기능 구현과 API 연동 작업을 담당하고 있습니다.<br/><br/>

단순히 화면만 만드는 개발자가 아니라, 서비스 운영 흐름과 안정성까지 고려하며 개발하는 것을 중요하게 생각합니다.
</sub>
